# @byodod/project-brain

Official npm distribution of [Project Brain](https://github.com/byodod/Project-Brain), a deterministic project
decision and memory control plane for coding agents.

## Install

```text
npm install --global @byodod/project-brain
project-brain --version
```

Or run one command without a permanent global installation:

```text
npx @byodod/project-brain --version
```

The package contains the verified native Rust CLI for all supported platforms. It does not run a `postinstall`
download script.

Supported targets:

- Windows x64
- Linux glibc x64
- macOS Intel x64
- macOS Apple Silicon arm64

Project setup and Agent integration instructions are available in the
[main documentation](https://github.com/byodod/Project-Brain/blob/main/docs/getting-started.md).
